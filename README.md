## 🌟 特徴・自動化の仕組み

### 1. 人的リソース 0 (完全自動化)
- **データ収集 → コンテンツ生成 → PR・収益化導線の挿入 → パブリッシュ** を GitHub Actions の定期Cronタスク（毎日自動起動）で完全自動処理します。
- 人間が記事を書いたり、サイトを修正・デプロイする必要は一切ありません。

### 2. 法的リスク 0 (徹底的な自動コンプライアンス)
- **景表法（ステマ規制対応）**: 広告・アフィリエイトリンクを含む全ページに「PR表記」をシステムレベルで自動強制適用。
- **著作権法（第30条の4 情報解析・引用）**: 公式APIおよび適切な引用・要約アルゴリズムを通過した安全なコンテンツのみ生成。
- **特定商取引法**: 大手ASP・Stripe等の決済を利用し、個人情報の露出トラブルを排除。

### 3. 初期経費 0円 (完全無料スタート)
- **Hosting**: Vercel / Cloudflare (完全無料)
- **CI/CD Cron**: GitHub Actions (月2,000分無料枠)
- **AI Engine**: Google Gemini API (無料利用枠)
