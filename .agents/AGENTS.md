# 自動マネタイズシステム プロジェクトルール

## デプロイ手順
- 本番URL: https://auto-monetize-system.vercel.app
- Vercelプロジェクト: `seitaimichibiki-8143s-projects/auto-monetize-system`
- デプロイコマンド: `npx -y vercel --prod --yes`
- GitHubプッシュだけでは自動デプロイされない場合があるため、Vercel CLIで明示的にデプロイすること
- Vercel CLIログインは `npx -y vercel link --yes` で実行可能

## コンテンツ品質基準
- 記事はマナブログ（manablog.org）およびトップメディア水準を目標とする
- ピラー・主要ガイド記事は**15,000文字級**の圧倒的ボリュームと超高密度ノウハウ記事であること（クラスター記事も最低4,000文字以上）
- 記事構造: 読者の悩み ➔ 信頼性 ➔ 📌結論ボックス ➔ 🎨グラデーションH2 ➔ 主張・理由・具体例 ➔ 💬会話風吹き出し・📖用語解説 ➔ 🔄ステップフロー ➔ 📊実名比較表 ➔ ⚠️注意点 ➔ まとめ
- 比較表は実在サービスの実名比較（架空の「他社A」等は禁止）
- 画像はテーマに合ったものを使用（全記事同一画像は禁止）
- リッチ装飾パーツ（`rich-summary-box`, `rich-h2-card`, `rich-balloon-wrap`, `rich-term-box`, `rich-point-card`, `rich-warning-card`, `rich-flow-container`）を全記事に必須配置すること

## コンテンツ運用
- 一括公開は15〜20記事が最適。30記事以上の一括公開はGoogleスパム判定リスクあり
- 記事追加時は4テーマ×5記事（ピラー1+クラスター4）の階層を維持
- 現在のカテゴリ: AI副業・自動化、AIテクノロジー、フリーランス、Webマーケティング
- サブエージェントで並行執筆する場合、JSONフィールド名の不一致（ads/ad/affiliateOffer）に注意し統合時にノーマライズすること
- 一時ファイル（posts_theme*.json）は統合後もリポジトリに残しておいてよい

## 広告マッチング＆アフィリエイト配置
- ランダム配置禁止。カテゴリベースの適切なマッチングを行うこと
- 記事テーマと広告の関連性を必ず確認すること
- **記事途中へのアフィリエイト配置**: 記事の末尾だけでなく、各H2章の直後や読者の関心が高まる文脈の途中に「DMM生成AI CAMP」「お名前.com」「freee」等の適切なアフィリエイトCTAカード・テキストリンクを必ず自然に挿入すること

## SEO構造＆内部リンク
- ピラー（まとめ記事）+クラスター（個別記事）の階層構造を維持
- 記事間の内部リンクを必ず設置すること
- 各章やH2直後に `» 参考： [記事タイトル](URL)` 形式の内部リンクを複数網羅すること
