# 自動マネタイズシステム プロジェクトルール

## デプロイ手順
- 本番URL: https://auto-monetize-system.vercel.app
- Vercelプロジェクト: `seitaimichibiki-8143s-projects/auto-monetize-system`
- デプロイコマンド: `npx -y vercel --prod --yes`
- GitHubプッシュだけでは自動デプロイされない場合があるため、Vercel CLIで明示的にデプロイすること
- Vercel CLIログインは `npx -y vercel link --yes` で実行可能

## コンテンツ品質基準
- 記事はマナブログ（manablog.org）水準を目標とする
- 各記事は4000文字以上の具体的なノウハウ記事であること
- 記事構造: 読者の悩み→信頼性→結論→主張→理由→具体例→反論回収→まとめ
- 比較表は実在サービスの実名比較（架空の「他社A」等は禁止）
- 画像はテーマに合ったものを使用（全記事同一画像は禁止）

## 広告マッチング
- ランダム配置禁止。カテゴリベースの適切なマッチングを行うこと
- 記事テーマと広告の関連性を必ず確認すること

## SEO構造
- ピラー（まとめ記事）+クラスター（個別記事）の階層構造を維持
- 記事間の内部リンクを必ず設置すること
- `» 参考：` `» 詳しくは：` 形式の内部リンクを使用
